# MapTiler Cloud — API de mapas para web e mobile: estilos customizados, hospedagem de geodados, geocoding, mapas estáticos, coordenadas e IP geolocation

🔗 https://www.maptiler.com/cloud

## Resumo

Página do MapTiler Cloud. Recursos: personalizar mapas online (idioma, cores, fontes da marca); upload e hospedagem de geodados (GeoTIFF, GeoJSON, Shapefile) por drag-and-drop ou API, processados automaticamente; edição de pontos, linhas e polígonos direto no mapa; Search & Geocoding (nome/endereço ↔ coordenadas, até nível de endereço, e reverso); Static Maps API (mapa como imagem); tiles raster para Leaflet/OpenLayers/XYZ, vetoriais para o MapTiler SDK, e WMTS para QGIS/ArcGIS; Coordinates API (códigos EPSG e conversão entre sistemas de coordenadas); IP Geolocation API. Conta grátis para uso pessoal e avaliação.

## Tópicos

- **Mapas** — Estilos personalizados; tiles raster/vetor; WMTS para QGIS/ArcGIS; mapas estáticos.
- **Dados** — Upload de GeoTIFF/GeoJSON/Shapefile; edição de geometrias.
- **APIs** — Geocoding, Coordinates (EPSG), IP Geolocation.

## Pontos-chave

- WMTS + QGIS e conversão EPSG falam a língua de engenharia civil/topografia.
- Mapa estático serve para PDF de laudo sem JavaScript.
- Hospedar Shapefile/GeoTIFF próprio (levantamentos) e servir no app.

## Como aplicar

Laudos e vistorias: mapa estático do imóvel no PDF e conversão de coordenadas SIRGAS/UTM via Coordinates API; comparar geocoding com Nominatim (grátis, no vault).

## 🔧 Atlas diz

Aqui tem parafuso de engenheiro: WMTS para o QGIS, conversão de EPSG por API e mapa estático para colar no laudo. Para geocodificar, o Nominatim que guardamos é grátis; o MapTiler entra quando precisar de mapa bonito no PDF.
