# awesome-mcp-servers: 3.793 servidores MCP catalogados em 69 categorias

🔗 https://github.com/punkpeye/awesome-mcp-servers

## Resumo

Lista curada de servidores MCP — os conectores que dão ao agente acesso a ferramentas e dados externos. O que foi guardado aqui é o MAPA ESTRUTURAL, não a lista de links: são 3.793 entradas em 69 seções, e os links mudam toda semana, então guardar a lista inteira envelheceria em dias e incharia o vault sem ganho. O que dura é a distribuição, e ela diz onde o ecossistema realmente está: Developer Tools lidera com 477 servidores, seguido de Finance & Fintech com 426, Knowledge & Memory com 314, Communication com 144, Databases com 130, Aggregators com 123 e Cloud Platforms com 114. Categorias de nicho como Acessibilidade e Identidade têm um servidor cada. O repositório tem README traduzido para nove idiomas, incluindo português do Brasil, e mais de onze mil commits — é catálogo vivo, mantido por contribuição contínua da comunidade. Para consulta pontual, o caminho certo é abrir a categoria no repositório na hora da necessidade, não decorar a lista.

## Tópicos

- **O que é um servidor MCP** — Conector que dá ao agente acesso a uma ferramenta ou fonte de dado externa — banco, navegador, API, sistema de arquivos — por um protocolo comum.
- **Onde o ecossistema se concentra** — Developer Tools 477, Finance & Fintech 426, Knowledge & Memory 314, Communication 144, Databases 130, Aggregators 123, Cloud Platforms 114 — os sete maiores de 69 categorias.
- **Categorias relevantes ao trabalho aqui** — Browser Automation 96, Coding Agents 81, Art & Culture 79, File Systems 45, Data Platforms 44, E-Commerce 31, Architecture & Design 23, Command Line 24.
- **Por que só o mapa foi guardado** — O README tem 1,5 MB e os links mudam semanalmente; guardar tudo envelheceria em dias. A distribuição por categoria é o que sobrevive e orienta a busca.
- **Alcance e manutenção** — Mais de onze mil commits e README traduzido para nove idiomas, incluindo português do Brasil — catálogo vivo mantido por contribuição da comunidade.

## Ferramentas citadas

- **MCP (Model Context Protocol)**: protocolo que padroniza como um agente pluga ferramentas e fontes de dados externas
