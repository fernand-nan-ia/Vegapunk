# Resend — SDKs oficiais e da comunidade (Node, PHP, Laravel, Python, Ruby, Go, Java, Rust, .NET) e OpenAPI

🔗 https://resend.com/docs/sdks

## Resumo

Lista de SDKs do Resend. Oficiais: Node.js, PHP, Laravel, Python, Ruby, Go, Java, Rust, .NET e um adaptador Chat SDK. Comunidade: Elixir, NestJS, Dart. Há especificação OpenAPI (resend/resend-openapi) para gerar clientes ou alimentar agentes.

## Tópicos

- **Oficiais** — Node, PHP, Laravel, Python, Ruby, Go, Java, Rust, .NET, Chat SDK.
- **Comunidade** — Elixir, NestJS, Dart.
- **OpenAPI** — Spec pública para gerar clientes.

## Pontos-chave

- Python é oficial — sem dependência de terceiros para o SaaS.
- OpenAPI serve para o Claude Code entender a API inteira.

## Como aplicar

pip install resend no SaaS; OpenAPI como referência para a Atlas.

## 🔧 Atlas diz

Python oficial: uma dependência a menos para desconfiar. Guardo o link do OpenAPI — quando for construir, é o mapa dos parafusos.
