# Resend — integrações: agentes de código, ferramentas de IA, no-code (n8n, Zapier, Make), notificações, CMS e dev tools

🔗 https://resend.com/docs/integrations

## Resumo

Catálogo de integrações do Resend. Agentes de código: Cursor, Claude (connector), Claude Code (plugin), Codex, Antigravity, Devin, Gemini, Copilot, OpenCode, Zed, Warp. IA/builders: Lovable, Anything, Wildcard, mcp.run, Rocket, Base44, Leap.new, Parsley, Pica, camelAI. No-code: n8n, Zapier, Pipedream, Activepieces, Make.com, Lindy, BuildShip, viaSocket, Stacksync, ApiX-Drive, Post SMTP (WordPress), Softr. Notificações: Courier, Novu, Knock, Engagespot, Dittofeed, Suprsend. CMS: Payload, Strapi. Dev tools: Raycast, Convex, Inngest, Upstash, Encore, Trigger.dev, Infisical e outros.

## Tópicos

- **Agentes de código** — Claude Code, Cursor, Codex, Copilot…
- **No-code** — n8n, Zapier, Make, Pipedream, Activepieces, Post SMTP.
- **Notificações e CMS** — Novu, Knock, Courier; Payload, Strapi.
- **Dev tools** — Inngest, Trigger.dev, Convex, Upstash, Raycast.

## Pontos-chave

- Site do cliente em WordPress pode enviar pelo Resend via Post SMTP sem código.
- n8n no VPS (item Hostinger) + Resend fecha automações sem escrever backend.
- Inngest/Trigger.dev servem para drip quando as Automations nativas não bastam.

## Como aplicar

Cliente em WordPress: Post SMTP + Resend; SaaS: SDK + Automations; Vegapunk: MCP.

## 🔧 Atlas diz

Catálogo, não ferramenta — mas útil para não construir o que já existe. Post SMTP resolve e-mail do site do cliente sem uma linha de código; n8n + Resend no VPS é automação sem backend. Guardado para consulta.
