# Prompt único de ChatGPT para gerar site e vender por R$ 1.500 (isca de treinamento)

🔗 https://www.tiktok.com/@ialucrativa._/photo/7670577644882234644

## Resumo

O carrossel promete ensinar a vender sites feitos com IA por até R$ 1.500 ou mais por projeto, sem saber programar. O método apresentado tem um passo só: pegar um prompt pronto no ChatGPT e colar numa ferramenta geradora de sites. O prompt pede um site premium, moderno e responsivo para um nicho a preencher, com design sofisticado, animações suaves, copy persuasiva, SEO, botão de WhatsApp, formulário de contato, Google Maps, portfólio, depoimentos, FAQ e CTAs, com aparência de agência profissional. As ferramentas sugeridas são Lovable, Gamma, Bolt e Claude. O terceiro passo é apenas esperar a IA gerar. O conteúdo real termina aí: os slides seguintes são isca para uma mensagem no direct pedindo acesso ao treinamento pago, que é onde estaria o resto (publicar, achar clientes, definir preço). O valor informativo é o texto do prompt e a lista de ferramentas; o resto é funil.

## Ferramentas citadas

- **ChatGPT**: onde o autor manda escrever/adaptar o prompt do site
- **Lovable**: gerador de site a partir do prompt
- **Gamma**: gerador de site/apresentação a partir do prompt
- **Bolt**: gerador de site a partir do prompt
- **Claude**: gerador de site a partir do prompt

## Pontos-chave

- O prompt pede num bloco só: design sofisticado, animações suaves, copy persuasiva, SEO, botão de WhatsApp, formulário de contato, Google Maps, portfólio, depoimentos, FAQ e CTAs.
- A faixa de preço citada para um site gerado assim é R$ 1.500 por projeto.
- O conteúdo entrega geração e para antes de publicação, prospecção, precificação e entrega — essas partes são o produto pago.
- Pedir tudo num prompt gigante tende a produzir página genérica de template, não um site do negócio do cliente.

## Como aplicar

A lista de elementos do prompt serve de checklist do que o mercado espera ver numa landing de pequeno negócio, e o R$ 1.500 é mais um ponto de referência de preço para o serviço. Mas o formulário de contato que o prompt inclui contraria a decisão de 07/09 de não ter formulário nas duas primeiras landings — botão wa.me só. Usar como referência de mercado, não como método.
