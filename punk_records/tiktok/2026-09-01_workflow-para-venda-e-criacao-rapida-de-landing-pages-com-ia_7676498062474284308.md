# Workflow para Venda e Criação Rápida de Landing Pages com IA

🔗 https://www.tiktok.com/@oreidosites/photo/7676498062474284308

## Resumo

O conteúdo apresenta um roteiro prático para faturar com a criação e venda de landing pages para pequenos comércios locais a R$ 1.000 por projeto. A esteira de produção utiliza o Claude para estruturar código HTML, CSS e JavaScript com foco em conversão e SEO, além da ferramenta Nano Banana para gerar ativos visuais personalizados. O deploy é realizado sem custo fixo inicial através de plataformas como Vercel, Netlify ou Cloudflare Pages integradas ao GitHub. Na etapa comercial, recomenda-se identificar negócios locais com sites ruins ou ausentes via Google Maps e Instagram, abordando-os com uma prévia pronta. Conclui-se enfatizando que o cliente compra o resultado de posicionamento digital e conversão, e não as linhas de código.

## Tópicos

- **Pipeline de Produção e Deploy** — Geração do código base e scripts via Claude, criação de imagens com Nano Banana e publicação gratuita via Vercel, Netlify ou Cloudflare Pages.
- **Prospecção Ativa e Fechamento** — Busca por estabelecimentos com presença deficiente no Google Maps e Instagram para apresentação de prévias antes do fechamento.

## Ferramentas citadas

- **Claude**: Geração rápida do código HTML, CSS e JavaScript da landing page focado em conversão e SEO
- **Nano Banana**: Geração de imagens personalizadas e elementos visuais para os sites
- **Vercel**: Hospedagem e deploy gratuito integrado ao GitHub
- **Netlify**: Plataforma alternativa para hospedagem e deploy gratuito de sites estáticos
- **Cloudflare Pages**: Hospedagem estática gratuita de alta performance para publicação rápida

## Pontos-chave

- O valor percebido pelo cliente leigo está no resultado comercial e visual, não na complexidade do código.
- O custo inicial de infraestrutura pode ser zerado utilizando planos gratuitos de plataformas de hospedagem modernas.
- A abordagem comercial com prévia pronta reduz a barreira de entrada para fechar contratos com negócios locais.

## Como aplicar

Pode ser aplicado diretamente na esteira de desenvolvimento de sites para clientes locais, acelerando o tempo de entrega com Claude e reduzindo custos de hospedagem com Vercel ou Cloudflare Pages.
