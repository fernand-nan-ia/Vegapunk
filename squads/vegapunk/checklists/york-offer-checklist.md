# Checklist: york-offer-checklist

Usado por York em `*offer` e `*pricing`. Condensado do hormozi-offers/hormozi-pricing, traduzido para o laboratório: cada item tem custo ao lado ou não entra.

## Value Equation (passar cada componente)
- [ ] Aumenta o **resultado** percebido? (frase com número, vida "depois")
- [ ] Aumenta a **probabilidade percebida**? (prova, caso real, demonstração, garantia)
- [ ] Reduz o **tempo** até o primeiro resultado? (vitória em 24–48h)
- [ ] Reduz o **esforço**? (template, automação, feito-para-você)
- [ ] Não move nenhum dos 4 → sai da oferta

## Problemas → soluções
- [ ] ≥ 8 problemas listados: antes · durante · depois
- [ ] Uma solução por problema; nenhuma pulada
- [ ] Cada solução tem veículo (1:1 · grupo · 1:N · DIY) e custo de entrega em R$ e em lanche

## Bônus
- [ ] Máximo 3; cada um com nome próprio, valor com base declarada, problema que mata
- [ ] Bônus resolve o PRÓXIMO problema depois do principal
- [ ] Barato de entregar, valioso de perceber; custo ao lado
- [ ] Bônus de ação rápida tem data real

## Garantia
- [ ] Tipo escolhido: incondicional · condicional · performance · anti-garantia
- [ ] Pior caso calculado: reembolsos/mês que o Fernando aguenta
- [ ] Performance só com confiança alta de entrega; anti-garantia só com fila
- [ ] Condicional exige condição que o cliente consegue provar que cumpriu

## Nome
- [ ] `[Resultado] + [Prazo] + [Formato]`; soa como coisa, não como serviço
- [ ] 3 opções geradas, 1 escolhida com motivo

## Preço
- [ ] Preço ≥ piso (custo × 1,25)
- [ ] Preço ≤ teto (1/10 do valor do resultado)
- [ ] Valor empilhado ≥ 5× preço, cada linha justificada
- [ ] Mostrado por dia/por resultado ("menos de um pastel por dia")
- [ ] Benchmark com fonte (link) ou "sem benchmark" explícito — nunca inventado
- [ ] Margem ≥ 70% SaaS · ≥ 50% serviço com horas
- [ ] "Tá caro" → empilhar valor, nunca desconto como primeira resposta

## Escassez/urgência
- [ ] Real (horas finitas, vagas de verdade, data de bônus); nunca falsa

## Encaminhamentos

- [ ] Hype na promessa → Lilith
- [ ] Vai implementar → Edison pergunta "coxinha ou jantar?"; York responde com o custo
- [ ] Texto de venda → não é aqui
