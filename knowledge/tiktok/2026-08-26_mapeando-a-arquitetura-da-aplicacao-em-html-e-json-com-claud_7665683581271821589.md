# Mapeando a Arquitetura da Aplicação em HTML e JSON com Claude

🔗 https://www.tiktok.com/@ot.oliver/video/7665683581271821589

## Resumo

Documentar bases de código complexas para agentes de IA pode ser desafiador e custoso em termos de contexto. A dica propõe pedir ao Claude para gerar a arquitetura completa do app em uma página HTML para visualização humana e em um JSON estruturado. Esse JSON serve como contexto rápido e preciso para os próximos agentes que implementarem novas funcionalidades.

## Ferramentas citadas

- **Claude**: Mapear a arquitetura do aplicativo e gerar documentação em formatos HTML e JSON

## Pontos-chave

- Gerar a arquitetura do sistema em um único arquivo HTML permite fácil consulta e visualização humana.
- Exportar a arquitetura em JSON cria um formato leve e estruturado para alimentar agentes de IA subsequentes com o contexto do projeto.
- A técnica torna a base de código autoexplicativa tanto para desenvolvedores quanto para fluxos automatizados de agentes.

## Como aplicar

Ao usar Claude Code no SaaS pessoal ou no site do cliente, gere periodicamente um arquivo `architecture.json` na raiz para injetar como contexto inicial para novas sessões e tarefas de agentes, além de manter um HTML de visualização rápida.
